SMQ LED Demo Introduction

The SMQ LED Demo shows how to design an IoT solution for controlling LEDs in devices connected to an SMQ broker. The demo uses the SMQ protocol and enables browser clients to control all LEDs in each connected device. See the Browser to Device LED Control using SMQ tutorial for details.

Connect Your Own Device

Run a ready-to-use demo or compile the device client source. Each connected device appears in the Devices pane with its network address.

Download:

The SMQ device C source code can be downloaded from the SMQ source code page.

Try a Simulated Device

Turn on a browser-based device to test discovery and LED control without external hardware.
